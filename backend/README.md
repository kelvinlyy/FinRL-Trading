# FinRL-X Backend

Python API layer for the redesigned FinRL-X web experience.

## Scope

The backend currently exposes **read-only Adaptive Rotation results** generated by the existing strategy pipeline.

Included:
- Health check
- Saved backtest run discovery
- Summary metrics from `backtest_*.csv`
- Trade log rows from `trade_log_*.csv`
- Chart file paths for `enhanced_backtest_*.png`

Not included:
- Live trading controls
- Settings persistence
- Generic strategy backtests
- Data quality scoring

## Run

```bash
PYTHONPATH=/workspace:/workspace/src uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

## Endpoints

| Endpoint | Purpose |
| --- | --- |
| `GET /health` | API health check |
| `GET /api/results` | List saved Adaptive Rotation runs |
| `GET /api/results/{run_id}` | Get one run with metrics and trade preview |
